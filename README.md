# HABUB E-commerce Project

A modern **React e-commerce application** with **Tailwind CSS**, **responsive design**, **cart functionality**, and **user authentication**. This project features a dynamic Navbar, mobile-friendly design, and localStorage persistence for the shopping cart.

---

## 🌐 Live Demo

Check out the live project here: [HABUB E-commerce Live](https://cute-mandazi-81e5cc.netlify.app/)

---

## 🛠 Features

- **Responsive Navbar**  
  - Desktop & mobile-friendly  
  - Hamburger menu on small screens  
  - Scroll effect with backdrop blur  

- **Cart System**  
  - Add/remove products  
  - Increase/decrease quantity  
  - Persist cart in `localStorage`  
  - Shows total items and price  

- **User Authentication**  
  - Login & logout  
  - Show user menu with “Your Orders”  
  - Auth-aware UI  

- **Search Bar** (Desktop)  
  - Placeholder for searching products  

- **Routing**  
  - React Router for navigating Home, Products, About, Cart, and Login pages  

---

## 💻 Tech Stack

- **React 18**  
- **React Router v6**  
- **Tailwind CSS**  
- **React Icons** for UI  
- **localStorage** for cart persistence  
- Firebase for authentication
